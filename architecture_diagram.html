Module 2: Vehicle Route

(Trajectory Tracking)
Data Sources
Plate data (Module 1, via API/DB), city camera network, OSM road map
Processing Pipeline
Candidate Retrieval
Levenshtein Distance (plate + timestamp + similarity)
Vehicle Re-Identification
OSNet / TransReID (cross-camera visual confirm)
Physics & Temporal Filter
Distance/time/speed logic validation
Road Graph Matching
OSM + NetworkX (snap to road, build graph)
Trajectory Reconstruction
Kalman Filter (sort, gap-fill, remove outliers)
Outputs: Chronological vehicle trajectory (camera sequence, travel time, road-based path) via Leaflet.js
